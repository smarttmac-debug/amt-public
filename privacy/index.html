隱私政策 / Privacy Policy

生效日期：2026-10-06

授權與資料範圍

AMT 供專案擁有者私人使用。Google 登入身分及電子郵件用於核對授權帳戶；Google Sheets API 用於讀寫 AMT 研究資料、預測、結果及稽核表；Google Docs API 用於讀取規格與範本並建立及核對研究文件。Drive-file 存取用於應用程式建立或由使用者明確授權的檔案及其必要中繼資料。AMT 不要求全域 Google Drive 存取權，正式流程使用指定資源識別值。

用途與處理

資料僅用於 AMT 市場研究、凍結輸入的預測、結果核對及可追溯稽核。研究輸入文件中經篩選的市場資料可送交 OpenAI API 以產生預測；不會將 OAuth 憑證送交模型。模型輸入、輸出與稽核產物保存在專案的 Google 文件、試算表或受限雲端儲存中。公開網站不含私人研究資料。

憑證與保存

無人值守授權使用的 OAuth refresh material 儲存於 GCP Secret Manager，與公開網站及原始碼分離。研究與稽核紀錄按專案稽核需要保留。撤銷授權會阻止後續授權存取，但不會自動刪除先前合法建立的稽核紀錄；資料刪除或存取問題請聯絡專案擁有者。

分享限制與撤銷

AMT 不販售 Google 使用者資料、不用於廣告，也不與廣告商分享。Google 資料僅依本政策所述用途由必要的雲端與模型服務處理。帳戶擁有者可隨時在 Google 帳戶的第三方連線設定撤銷存取。

Google API Limited Use

AMT 對 Google API 所取得資訊的使用及向其他應用程式傳送資訊，遵守 Google API Services User Data Policy，包含 Limited Use 要求。Google 使用者資料不作廣泛用途 AI／ML 模型的訓練資料。

AMT's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access is for the project owner's authorized research workflow; no sale, advertising use or advertiser sharing occurs.
